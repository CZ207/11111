# Griffin 秋招作品集网站 · V3 Spec

版本：3.0  
日期：2026-08-16  
状态：已确认，按此实施

## 1. 目标与定位

这是一个“证据优先”的求职作品集，不是第二个个人主页。

- 10 秒内看清候选人定位：产品判断、沟通推进、效率工具、复杂信息整合。
- 30 秒内看到 6 组经历及其最强证据。
- 首页只承担快速扫描和分流；详细过程进入独立案例页。
- 所有内容达到可直接投递状态，不出现“素材不足”“暂无内容”“不能瞎编”等草稿提示。
- 事实与归属准确：字节跳动为“人才交付运营 / 人力资源运营”，不改写为产品岗位。

## 2. 信息架构

### 首页：项目桌面

1. 紧凑导航：姓名 / 项目桌面 / 简历 / 联系方式。
2. Hero：浅色编辑台、原色照片、七张窄幅证据卡、三个不同动作的软质 3D 人物点缀与四个能力标签。
3. Bento 项目桌面：6 个尺度不同但共享边界的项目入口；首组由 7 列主案例跨两行，右侧两张 5 列专题卡各占一行，次组为三张等宽卡，保证“不规则”建立在清晰栅格上。
4. 轻量经历索引：公司、岗位、时间、案例入口，不再重复长篇叙述。
5. Footer：简历、研究报告、邮箱、电话。

### 独立案例页

- `case-netease-tools.html`：网易云音乐笔记产品运营全链路；Music Plus 与 POPO Reviewer 是提效层。
- `case-netease-sports.html`：网易经历下的深挖专题；五平台运动新品类研究 + 抖音 / 小红书 Figma 产品拆解。
- `case-one2x.html`：Medeo 推广增长、热点与内容运营、Recipe 调优、VideoClaw 测试、研发协同与用户研究。
- `case-bytedance.html`：人才交付运营 / 人力资源运营工作流重绘。
- `case-foreign.html`：中国外文局中英编译交付物。
- `case-xdf.html`：新东方教学交付系统、真实目录与材料证据。

每页固定包含：

1. 左上角粘性“← 返回项目桌面”。
2. 角色 / 时间 / 任务类型。
3. 一句话结果或工作判断。
4. 工作逻辑或流程图。
5. 证据墙：截图、文档、视频或重绘图。
6. 上一案例 / 下一案例。

## 3. 视觉系统

### 参考原则

主参考 `_Framer Business Site_ Responsive, Ready-Made Template_`：借用中心叙事、浅色编辑台、扇形窄幅证据、紧凑 Bento 和强层级；深色纸纹保留个人识别度。

### 气质

高级、编辑感、温暖、克制、有手工纸张触感；不做科技感、赛博朋克、玻璃拟态整站或 AI 网格背景。

### 色彩

| Token | 值 | 用途 |
|---|---|---|
| `kraft-950` | `#17110e` | 页面主背景 |
| `kraft-900` | `#211712` | 深色卡片 |
| `kraft-800` | `#30231c` | 次级卡片 / 线条 |
| `cream` | `#f1e8d8` | 主文字 / 浅卡片 |
| `cream-soft` | `#d5c8b6` | 次级文字 |
| `amber` | `#d29a4a` | 关键动作与数字 |
| `moss` | `#71806a` | 研究 / 系统 |
| `rose` | `#a96f6b` | 内容 / 人物 |
| `ink` | `#191513` | 浅色卡片文字 |

### 背景纹理

- 使用真实的深棕色纸张纹理图片，并叠加低对比度深棕渐变；当前采用可自由使用的公共领域纸张素材。
- 禁止规则点阵、网格、发光圆圈、霓虹光晕。
- 纹理对比度低，不干扰正文。

### 字体与层级

- 无外部字体依赖。
- 中文：`Microsoft YaHei` / `PingFang SC`。
- 编辑感标题：`Georgia` 与中文无衬线混排。
- 首页 Display：`clamp(46px, 6vw, 82px)`；案例 H1：`clamp(42px, 6vw, 76px)`。
- 正文 15–17px，行高 1.7；证据说明 12–13px。
- 同层级字号、字重、间距与圆角只能有一套。

## 4. 组件规范

### 项目卡

- 统一包含：项目序号、公司与岗位、标题、时间、能力标签、一句结果、证据缩略图、明确箭头。
- 卡片整块可点击；键盘可聚焦；Hover 只增加位移/层次，不承载唯一信息。
- 首页网格为 12 列：网易主案例占 7 列并跨两行，运动专题与 Medeo 各占右侧 5 列一行，字节 / 外文局 / 新东方各占 4 列；桌面端所有外边界与行高对齐。
- 专题卡证据图进入正常内容流，不贴底裁切；缩略图使用 `object-fit: contain` 完整呈现，允许留白但不允许牺牲信息。
- 1050px 以下转为两列组合，780px 以下转为单列；顺序始终保持主案例 → 运动专题 → Medeo → 其余经历。

### 证据墙

- 使用错落堆叠、折页、横向轨道与文档桌面等不同构图，但边框、圆角、阴影与说明样式统一。
- 点击图片进入 Lightbox；支持 Esc、左右方向键、关闭按钮。
- 证据说明必须回答“这张图证明什么”，而不是重复文件名。

### 隐私玻璃

- 工作截图的原始文件不修改；网站使用复制件。外文局四份 DOCX 根据用户明确要求直接优化，覆盖前单独建立可恢复备份。
- 底层敏感区域先做局部像素模糊，避免打开原图泄露。
- 表层使用真正透明玻璃：`rgba(243,235,220,.14)` + `backdrop-filter: blur(18px) saturate(.55)` + 半透明描边与高光。
- 禁止实心灰色色块。

### 人物素材

- 原始照片不应用 `filter`、调色、色偏或对比度处理。
- 卡通形象采用 Gugugaga 类软质 3D Q 版方向，生成“探头指向 / 坐着记笔记 / 抱卡片行走”三个动作，只作页面边缘点缀，不单独占据封面卡。

### 首页扇形入口封面 · 2026-08-17

- 七张卡片采用统一的竖幅 2:3 视觉系统；第 4 张保留原色本人照片，其余 6 张使用同一位软质 3D Q 版角色重新生成，不再直接使用项目截图。
- 角色锚点：中分短黑发、深棕大眼、年轻东亚男性面部特征、圆润头身比与细腻磨砂玩具材质；默认黑色轻正装，可按场景加入衬衫、袖套或教师外套，但不得改变脸型、发型与整体材质。
- 构图锚点：主体和关键动作集中在画面上方及中部；底部约 20% 避免放置不可遮挡的信息，为卡片标签留出安全区。
- 统一风格：高级软质 3D 动画电影感、温暖编辑光、奶油纸张与深棕木质空间、低饱和环境色；不使用赛博朋克、科技蓝光、复古油画、写实照片感或廉价卡通贴纸感。
- 场景顺序：①黑板双语编译与满桌译稿；②淡化的网易云音乐红色旋涡标识与电脑前产品/品类研究；③大屏 AI 视频制作，周围出现小猫、泛女团舞台与足球热点画面；④本人原色照片；⑤活动上线运营，多任务奔走与分身虚影；⑥拆解工作流程并把模块整合为工具；⑦教室讲授雅思阅读，学生认真听讲。
- 图片内不出现中文；能用动作、道具、屏幕画面和空间关系表达的内容不使用文字。允许极少量抽象英文符号，但禁止大标题、乱码、品牌口号和水印。
- 桌面端卡片采用浅弧扇形阵列：普通卡约 `194 × 276px`，中央人物卡约 `216 × 306px`；外侧卡只允许轻微边缘裁切，不允许被人物点缀遮挡。
- 卡片使用 3px 内衬与 1px 半透明亮边，叠加底部电影式渐变、双层柔和阴影和悬浮上移，避免厚重白框与贴纸感。
- 首屏入口统一使用“能力领域｜工作场景”命名；项目桌面统一使用“主题：工作范围”标题，避免公司、岗位、成果、英文项目名混用造成层级混乱。
- 两个首屏卡通点缀放大后固定在文案区两侧留白，项目桌面人物放大并置于标题右上留白；1050px 以下缩减或隐藏，不进入卡片点击区。
- 全站页面右下角统一提供无文字返回顶部按钮；滚动 420px 后出现，支持键盘焦点、减少动态偏好与移动端安全边距。
- 保留系统光标；增加一个小型暖色跟随光点，交互元素上轻微放大，不影响可用性。

## 5. 内容口径

### 网易云音乐 · 2026.07—至今

- 团队：音乐事业部 / 产品运营中心。
- 岗位：产品运营。
- 核心经历链：笔记板块活动策划 → 上线物料与 QA → 发布运营 → 用户及创作者反馈 → 创作者中心优化 → 竞品与业务研究。
- 工具属于提效层，不用 Music Plus / POPO Reviewer 替代对整段工作经历的描述。
- POPO Reviewer：实际回溯约 200 条 / 3h → 400 条 / 2h，表述为“审核吞吐约 3 倍”，并注明非严格实验。
- Music Plus：第一版因样本少而模板化；补充新样本并调整 Prompt 后改善输出。
- 运动新品类研究：覆盖小红书、抖音、大众点评、得物、豆瓣；展示品类树、机会图、Figma 中的抖音和小红书产品拆解。

### One2X / Medeo · 2026.05—2026.07

- 个人工作：推广与用户增长、热点选题、内容生产与运营上线、Recipe 生产设计及调优、用户反馈、VideoClaw 测试、研发协同、社交媒体用户研究。
- 365 条 / 131,602 播放 / 8,128 互动为团队第一周期口径。
- 20M 看板仅作为平台全局参照，不归因为个人工作结果。
- 研究报告提供站内阅读与下载入口。

### 字节跳动 · 2025.07—2025.09

- 岗位：人才交付运营 / 人力资源运营（数据运营侧）。
- 不使用“内容运营”“产品运营”等错误标题。
- 用真实工作逻辑重绘：需求澄清 → 人才画像 → 数据筛选 → 触达协同 → 面试反馈 → 交付复盘。
- 强调数据定位漏斗卡点、沟通协调与交付节奏，不虚构产品案例或强数字。

### 中国外文局 · 2024.07—2024.09

- 岗位：国际传播运营。
- 展示快捷支付、杭州亚运会、雅加达—万隆高铁、卡车经济纽带四份中英编译交付物。
- 四份原 DOCX 已升级为专业编译审校稿：封面元信息、四色批注图例、术语表、逐段双语对照、事实/表达/风险批注、交付检查与编辑复盘。
- 覆盖前备份目录：`优化前备份-20260816`；网站另提供 PDF 在线阅读与 DOCX 下载副本。
- 不使用无原始记录的 98%、500+ 等强数字。

### 新东方 · 2026.01—2026.03

- 岗位：学术讲师。
- 逻辑图：诊断学情 → 选材与备课 → 课堂讲解 → 练习反馈 → 下一轮调整。
- 证据：真实工作目录、个人培训笔记、1v1 阅读材料、备课包、实习证明。
- 机构通用课件标注为工作上下文，不声称个人原创；学生姓名匿名化。

## 6. 交互与响应式

- 页面切换使用普通链接，浏览器返回可用。
- 案例页返回按钮在桌面与手机均固定可见，触摸目标至少 44px。
- 轻量滚动显现；总时长 220–500ms；`prefers-reduced-motion` 下全部关闭。
- 首页项目卡在手机单列，不保留难操作的错位悬浮。
- 视频 `preload="metadata"`、`playsinline`，由用户控制播放。
- 所有图片有 Alt；焦点状态清晰；正文对比度满足 WCAG AA。

## 7. 验收标准

- 首页不再是从上到下展开全部经历的个人主页结构。
- 6 个案例入口均可打开；每个案例页有可靠返回路径。
- 字节岗位准确，没有产品化改名。
- 原照片无滤镜；卡通形象为 Gugugaga 类软质 3D。
- 抖音、小红书 Figma 图、外文局材料、更多 Medeo 数据、新东方材料完整出现。
- 无“暂无素材”“没有具体信息”等草稿话术。
- 隐私遮挡为透明玻璃质感，放大图也不会泄露敏感字段。
- 1440×900、1024×768、390×844 三种尺寸无横向溢出、遮挡和不可点击元素。
- 对抗性检查中 P0/P1 全部修复后交付。
