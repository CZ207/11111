# 个人网站 8.18 最终版

## 打开方式

双击根目录的 `index.html`。入口页上方可直接进入代表作品集，下方刮刮乐进入个人叙事网站。

## 部署方式

部署时上传本文件夹内的全部内容，并保持目录结构不变。网站入口文件为根目录 `index.html`，作品集入口为 `portfolio/index.html`。

## 目录

- `index.html`：个人网站与双通道入口。
- 根目录 JPG：个人网站实际使用的照片素材。
- `portfolio/`：完整作品集、六个案例页、研究报告、网页简历、图片、视频和下载文档。
- `PROJECT-SPEC.md`：整合规范。
- `portfolio/SPEC.md`：作品集视觉与内容规范。
- `portfolio/QA-REPORT.md`：作品集检查记录。

不要单独移动 `portfolio/` 内的 HTML 或 `assets/`，否则相对链接会失效。
